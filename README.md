# Student Performance Analytics Dashboard Project

## Problem Statement

Educational institutions require early warning systems to identify students who may fail or drop out due to poor academic performance.

## Objective

To analyze student performance data and highlight performance trends and at-risk students for timely academic intervention.

## Dataset

Student performance dataset containing marks, attendance percentage, and LMS login activity.

## Tools Used

* Python
* Pandas
* NumPy
* Plotly
* Streamlit

## Analysis Performed

* Average marks and attendance calculation
* Correlation analysis between marks, attendance, and logins
* Absenteeism impact analysis
* Risk score calculation
* Student classification into high, moderate, and low risk categories

## Visualizations

* Bar charts comparing top and struggling students
* Heatmap showing correlation between features
* Scatter plot illustrating attendance impact on marks
* Risk table highlighting at-risk students

## Key Takeaways

* Low attendance negatively impacts academic performance
* Higher login activity correlates with better marks
* At-risk students can be identified early
* Dashboard supports data-driven academic interventions
